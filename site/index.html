Describe a device. Watch it get built.

V-Hbuild turns one sentence into the parts list, the wiring, compiled firmware and a 3D-printable enclosure, then plays the build in 3D. The desktop app sends the enclosure to your printer and flashes the firmware onto your board.

How it works

A small AI model chooses the parts and describes the behaviour. Everything electrical is done by plain code, so the result is correct even when the model isn't clever.

1 · Plan

The model picks parts

A local model (through Ollama) chooses from a catalog of real parts. It cannot invent one.

2 · Engineer

Code does the electronics

Pins, I2C addresses, power budget, resistors and level shifting. Bad plans go back to the model with the reasons.

3 · Program

Rules become firmware

The model describes behaviour as rules; V-Hbuild writes the C++ and compiles it for an ESP32 or a Pico W.

4 · Build

One file for every machine

The .vbuild holds the 3D build, a 3MF for your slicer and the firmware image for your board.

Get it

  • Windows installer and macOS app. Opens .vbuild files, prints and flashes.
  • Ollama with a model: ollama pull llama3.2:3b
  • Optional: PlatformIO to compile firmware into the file

Or run it from source:

pip install -r requirements.txt
python -m vhbuild.desktop

Honest limits

  • A small catalog: 3 boards and 16 modules.
  • Ready-made modules and jumper wires, not custom circuit boards.
  • A simple rectangular enclosure; check the fit before a long print.
  • Early software (v0.3). Contributions welcome, especially new parts.
